# Security Policy

## Supported Versions

Security fixes are currently provided for the latest stable release line.

| Version | Supported |
| ------- | --------- |
| 0.2.x   | Yes       |
| 0.1.x   | No        |
| < 0.1   | No        |

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for an undisclosed security vulnerability.

The preferred reporting method is GitHub's private vulnerability reporting feature when it is enabled for this repository. GitHub provides a private channel for reporting vulnerabilities directly to repository maintainers. [Private vulnerability reporting documentation](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately?utm_source=chatgpt.com)

When reporting a vulnerability, please include:

* A clear description of the issue
* The affected yspm version
* Steps to reproduce the problem
* The expected and actual behavior
* Any relevant logs, proof-of-concept code, or other technical details

Please allow time for the issue to be investigated before publicly disclosing technical details.

## Response

Reports will be reviewed as soon as reasonably possible.

Depending on the severity and reproducibility of the issue, the project may:

1. Confirm the vulnerability and investigate its impact
2. Request additional information
3. Prepare and test a fix
4. Publish a patched release or security advisory when appropriate

Not every report will necessarily result in a security advisory. Reports may be closed when the issue is not considered a security vulnerability, cannot be reproduced, or is outside the scope of the project.

## Disclosure

Please avoid public disclosure of vulnerability details until a fix or appropriate mitigation is available.

Security advisories on GitHub can be used to privately discuss, fix, and later publish information about vulnerabilities in public repositories. [GitHub repository security advisories](https://docs.github.com/en/code-security/concepts/vulnerability-reporting-and-management/repository-security-advisories?utm_source=chatgpt.com)
